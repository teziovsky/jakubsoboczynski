## Editor + Terminal

- I'm currently using [Cursor](https://cursor.com/).
  - [Rebased](https://github.com/detachhead/rebased) for merge commits.
  - Default Cursor theme with a few small modifications.

- [Zed](https://zed.dev/) thanks to its Blazingly Fast 🚀 performance, may replace [Cursor](https://cursor.com/) in the future for some workflows. For now, I mainly use it for quick text file editing.
- I love [Ghostty](https://ghostty.org/) for its incredible speed and modern features. Previously I used [Warp](https://www.warp.dev/) and as an alternative, I can highly recommend [iTerm2](https://iterm2.com/)[](https://fig.io/) - it has never let me down!
  - [Zsh](https://www.zsh.org/) + [oh-my-zsh](https://ohmyz.sh/) with plugins ([zsh-syntax-highlighting](https://github.com/zsh-users/zsh-syntax-highlighting), [zsh-autosuggestions](https://github.com/zsh-users/zsh-autosuggestions), [brew](https://brew.sh/index_pl)).

- [Helium](https://helium.computer/) is my main browser now. [Arc](https://arc.net/) is no longer supported, and [Dia](https://www.diabrowser.com/) hasn't convinced me with its feature set.

## Software

- Absolutely I can't imagine not using [Raycast](https://www.raycast.com/) 🔥 You can find a detailed description of how much I use this [application here](https://www.raycast.com/community-stories/jakub-soboczynski)! It's no coincidence that it's ranked first on the list 😎 For the purpose of app development, I have created several extensions. I also use it as my text expander, which works great for this purpose! Raycast scripts have also replaced [Keyboard Maestro](https://www.keyboardmaestro.com/main/) for the automations I still need.
  - [Raycast Height](https://www.raycast.com/teziovsky/height).
  - [Raycast inFakt](https://www.raycast.com/teziovsky/infakt).
  - [Raycast Raydocs](https://www.raycast.com/teziovsky/raydocs).
  - [Raycast CSS Calculations](https://www.raycast.com/teziovsky/css-calculations).

- [Linear](https://linear.app/) is an excellent project management tool that I highly recommend!
- The transition from Windows to macOS wasn't easy in the first few days due to keyboard layout habits. However, [Karabiner-Elements](https://karabiner-elements.pqrs.org/) solved those problems. Thanks to it, the `⇪ Caps Lock` key stopped being useless - now pressing it simulates pressing `⇧+⌃+⌘+⌥` keys, functioning as a Hyper Key! Additionally, I created my own Complex modifications with more advanced system modifications.
- [Hazel](https://www.noodlesoft.com/) ensures order in the Downloads folder and automatically organizes and moves files according to defined rules.
- [Proton Pass](https://proton.me/pass) remembers all my passwords 🔐 - [1Password](https://1password.com/) got too expensive, and I don't need that many features. Proton Pass is enough (before that I also used [Bitwarden](https://bitwarden.com/)).
- [Mole for Mac](https://mole.fit) takes care of keeping macOS clean 🧹 (previously ~~[CleanMyMac X](https://cleanmymac.com/pl)~~ and [Pearcleaner](https://github.com/alienator88/Pearcleaner)).
- [Apple Notes](https://apps.apple.com/us/app/notes/id1110145109) as a center for notes 📔
- [Contexts](https://contexts.co/) for fast window switching - I went back to it after a stint with [AltTab](https://alt-tab-macos.netlify.app/).
- [CleanShot X](https://cleanshot.com/) for all my screenshot needs, including OCR capabilities (previously used [TextSniper](https://textsniper.app/) just for OCR)
- [Clop](https://lowtechguys.com/clop/) automatically optimizes images and videos I copy to the clipboard.
- Without [Yoink](https://apps.apple.com/pl/app/yoink-improved-drag-and-drop/id457622435?l=pl&mt=12), moving files in macOS can be a tedious task 😡
- [LocalSend](https://localsend.org/) for quickly sharing files between devices on the local network.
- [Yaak](https://yaak.app/) as my API client.
- [Tailscale](https://tailscale.com/) for easy, secure access to my devices wherever I am.
- [Downie](https://software.charliemonroe.net/downie/) when I need to download a video from the web.
- [HandBrake](https://handbrake.fr/) for converting and compressing video files.
- [OpenLogi](https://openlogi.org/en) to customize my Logitech Lift.
- [Apple Music](https://www.apple.com/pl/apple-music/) - I mean you, Techno 🖤
- [Better Display](https://github.com/waydabber/BetterDisplay) for managing external displays - it's a powerful open-source tool!
